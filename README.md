# 3D-Studio
3D Studio is a Flask &amp; Three.js web-based 3D viewer and converter for STEP, IGES, STL, OBJ, and 3MF. It features real-time preview, precise analysis (face count, volume, surface area), multi‑format conversion, batch processing, section planes, version history, dark mode, and solar term themes—delivering a smooth, intuitive 3D experience.
